## 一、协作协议（所有 AI 必须遵守）

1. **改前**：通读本文件 + `plans/` 下相关文档；用代码核实现状（文档可能滞后于代码，以代码为准，但以文档为意图）。
2. **改后必须回写本文件**：
   - 「五、改动日志」追加一条（日期 + 版本 + 改了什么 + 影响哪些文件）
   - 「三、会员规则」如果被改动 → 直接更新对应条目并注明日期
   - 「六、待办」勾掉完成项/追加新发现
3. **版本号铁律**：每次发版 `package.json` version +1，构建文件名自带版本。打完包验证三件套：两个 exe 存在 + license-policy JSON 可解析 + after-pack 日志（fuses/license-policy/integrity）。
4. **验证要求**：typecheck 两侧全绿（`node node_modules\typescript\bin\tsc --noEmit -p tsconfig.web.json` / `tsconfig.node.json`）+ 单测 `node scripts/clean-env.cjs npm run test:unit`（基线 1043+）。
5. **删除类操作、生产服务器变更**：必须先经用户确认。
6. **禁止**：把 SSH 密码/SMTP 授权码写进任何会提交 git 的文件；服务端 404/403 文案里出现"不存在/找不到"字样（会触发客户端误报规则，见七）。
7. **Git 固化流程**：每组可独立说明的改动都要先精确暂存，再运行 `npm run git:check -- --strict`，通过后用 `npm run git:checkpoint -- "type: 简短说明"` 创建本地提交，最后运行 `npm run git:verify`；脚本不会自动 `git add`、不会 push、不会删除未跟踪文件。详细规则见根目录 `CONTRIBUTING-GIT.md`。

## 三、会员规则定稿 v2（2026-09-29 用户拍板，改动需用户确认）

### 三态身份 × 能力

| 能力 | 免费（试用结束） | 试用 VIP（24h 体验） | 充值 VIP（卡密） |
|---|---|---|---|
| 本地项目/编辑/论文排版 | ✅ | ✅ | ✅ |
| AI 对话 | 扣每日积分（100 分/天，签到 +100 分） | **不限 & 不扣积分** | **不限 & 不扣积分** |
| 论文写作 / **导出 Word/PDF/LaTeX** | ✅（按所选技能扣分；导出本身不另扣） | ✅ | ✅ |
| 高级图表 / 长上下文 | ✅（扣积分） | ✅ | ✅ |
| **多智能体协作** | ❌ 灰蒙 | ❌ 灰蒙 | ✅ |
| **AI 全自动模式**（decisionMode=auto） | ❌ 灰蒙 | ❌ 灰蒙 | ✅ |
| **深度建模**（modelingQualityMode=strict） | ❌ 灰蒙 | ❌ 灰蒙 | ✅ |
| 云端协作/自动化任务 | ❌ 灰蒙 | ❌ 灰蒙 | ✅ |

**核心规则**：
- **积分**：免费用户不带 `#` 的普通对话按 10 分/轮；选中 `#` 后按 62 个内置技能目录中的独立成本扣一次，不把普通档与技能档叠加；严格建模/多智能体/AI 全自动等付费能力走 feature 墙不扣分。试用/充值 VIP 不扣。**会员中心与 `#` 面板可以显示规则和每个技能的成本**，但服务端仍按白名单重算，余额不足提示不暴露内部请求栈。
- **付费独占（PAID_ONLY）只剩四项**：multi-agent / automation / deep-modeling / cloud-collaboration——**试用 VIP 也不可用**（服务端 PAID_ONLY_FEATURES 已强制）。其余一切不设墙。
- **注册奖励**：+50 奖励积分（服务端 `awardPoints('register',50)` 幂等，老账号首次请求自动到账）。
- **锁定样式**：`is-membership-locked` 灰色蒙版（grayscale + opacity .55，cursor not-allowed），**功能名上禁止挂「· VIP」字样**；点击锁定项仍引导到会员中心/注册（转化路径）。
- **套餐**（渠道定价，服务端不存价格）：体验 7 天 ¥9.9 · 月卡 30 天 ¥29 · 长期会员 3650 天 ¥99（不使用“永久/终身”措辞，服务端按有效期计算）。

### 签到
人人可签；免费号 +100 每日积分；试用/VIP 保留小额奖励（以服务端 CHECKIN_BONUS_POINTS=100 为准）。
