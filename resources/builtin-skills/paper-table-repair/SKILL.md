# 论文表格修复

先编译并定位实际出问题的 PDF 页面，再回到源文件修复。优先使用可换行列、`longtable`、拆分宽表和缩短表头；只有短数字矩阵才使用整体缩放。不得把长表压到正文中无法阅读。

每次修复后重新编译并检查表格所在页面，记录修复前后页数、宽度和可读性。输出 `solve/table-layout-report.md`，注明已经修复、仍有风险和需要人工确认的表格。
