# 结果复现

建立“结论 → 图表/表格 → 结果文件 → 脚本 → 输入数据”的证据链。检查脚本是否可运行、数据路径是否稳定、随机种子是否记录、输出是否来自最新代码，以及论文正文是否引用了历史版本结果。

输出 `solve/reproducibility-report.md` 与 `solve/result-manifest.json`。每个关键数字标记为已复现、无法复现或需要人工确认。发现正文、图表和代码不一致时，先停止写作并报告具体文件和数字。
