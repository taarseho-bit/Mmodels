# 模型选型核验

根据题目目标、数据规模、变量类型、约束、可解释性和计算预算建立候选表。至少保留一个可解释的基线模型，不把复杂模型的单次结果直接当作最佳答案。

输出 `solve/model-selection.md`，包含：题目特征、候选方法、数据要求、优缺点、风险、验证方式和最终选择理由。主方案必须说明为什么适合当前题目，备选方案必须说明何时切换。

如果题目是优化问题，记录可行性、求解状态和最优性证据；如果是预测或评价问题，记录评价指标、交叉验证方案和基线差距。结论写入论文前，提醒主智能体读取这份选型记录。
