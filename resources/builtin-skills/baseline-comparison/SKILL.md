# 基线对比

先根据题型选择一个能手算或快速复现的基线：均值/历史值、线性模型、规则排序、贪心方案、简单分配或小规模穷举。保持数据切分、指标口径和约束条件与主模型一致。

输出 `solve/baseline-comparison.md` 和可复现脚本。至少报告主模型与基线的指标、差值、运行状态、适用范围和失败情况。主模型没有稳定超过基线时，不得把复杂度写成优势；差距很小时优先选择更易解释的方案。
