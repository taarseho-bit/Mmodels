# 提交包检查

先读取项目比赛信息和提交规则，再确定最终论文文件。检查页数、文件命名、目录结构、PDF 是否可打开、图片和字体是否嵌入、图表是否存在、源文件和代码是否齐全，以及目录中是否混入临时文件、历史版本或个人信息。

输出 `solve/submission-package-report.md`。把结果分为“已确认”“需要处理”“需要人工确认”，不要因为目录中存在 PDF 就判定提交合格。可以生成一个新的提交目录，但不得删除用户原始文件。
