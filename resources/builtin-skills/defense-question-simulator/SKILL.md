# 答辩模拟

先读取最终论文、模型方案、验证记录和比赛信息，再生成分层问题：基础说明、方法选择、数据可信度、结果解释、极端情况、模型局限和改进方向。每个问题给出回答要点和对应证据文件，不编造论文中不存在的结果。

输出 `solve/defense-questions.md`。优先生成评委最可能追问的 10～20 个问题，并标记哪些问题需要重新运行模型或补充材料。
