# 数学建模论文表格排版审计

表格能成功编译，不代表它在 PDF 里完整可读。每个表格都必须在最终纸张宽度内，表头和长文本要能换行，跨页表格要重复表头，不能把右侧列藏到页面外。

## 固定流程

1. 找到论文主文件以及它引用的表格文件，确认实际使用的模板和正文宽度。
2. 运行 `scripts/check_table_layout.py <论文目录或 tex 文件>`，先列出宽表、原始 `tabular`、没有列定义的表格和可能跨页的表格。
3. 按下面顺序修复：
   - 文字列改为 `tabularx` 的 `X` 列，数字列使用 `S` 或 `r`，不要把一整段说明塞进 `c` 列；
   - 仍然过宽时拆成“方案与指标”和“资源与缺口”两张表，保持同一编号下的子表；
   - 需要跨页时使用 `longtable`，设置 `\endfirsthead`、`\endhead` 重复表头；
   - 只有短数字矩阵才允许 `\resizebox{\linewidth}{!}{...}`，不能靠缩到极小字号解决长文字；
   - 方向性很强、列数确实不能拆的表格使用 `sidewaystable` 或单独横向页，并在 PDF 中确认页码与表题正常；
   - Markdown 或 HTML 转 PDF 时先把表格转换为可分页的 LaTeX/HTML 表格，不把一个宽表当成一张图片。
4. 用 XeLaTeX 或项目已有构建方式重新编译。
5. 用 `pdftoppm` 渲染包含表格的页面，检查右边界、表头、数字对齐、中文字体和表题与正文的距离。
6. 只有视觉检查通过后，才把 PDF 交给页数压缩和提交核验。

## 交付要求

- 表格右边界不能超过正文边界。
- 表头不能被裁切，长字段必须换行或拆分。
- 表格不能覆盖页码、图题、正文或页边距。
- 表格内的数值必须来自最终验证结果，排版修复不能改动模型结论。
- 日志中的 `Overfull \\hbox`、`Underfull \\hbox` 要区分处理；宽表相关的 overfull 必须修复，不能只隐藏警告。
