# 第三方依赖与资料归属说明

本项目的产品名称、界面文案、任务编排、技能入口和数据目录由 MModels 自行维护。仓库中少量第三方库、图标、论文模板和公开资料仅作为可选能力或格式参考使用，不代表产品与其作者、组织或平台存在关联。

为遵守相应许可证，以下内容会原样保留必要的许可证头、版权声明、作者名和来源链接：

- `resources/**/LICENSE`、`NOTICE`、`ATTRIBUTION.md` 等法律归属文件；
- 论文模板源文件中由许可证要求保留的版权/维护者信息；
- 学术资料中的作者、出处和引用信息。

这些信息不会作为 MModels 的默认用户名、功能名称、供应商名称或界面品牌展示。产品代码和用户可见文案不得新增个人姓名、开发机路径、外部产品比较语句或未经授权的品牌标识。

当第三方资料需要替换或升级时，先检查其许可证，再在本目录补充来源、版本和变更记录；不要通过删除归属信息来制造“自有”标识。

本轮核查中，华数杯模板的上游仓库采用 MIT 许可证，许可证副本已随模板保留。此前内置的 MathorCup 模板没有查到可用于再分发的许可证，已从内置资源撤下；比赛日历条目仍保留。若将来获得明确授权，或完成独立编写并审查的新模板，才重新加入。
