# MModels 产品截图目录

请把真实软件截图按功能放入对应文件夹。文件名建议使用：

`编号-页面-功能-状态.png`

例如：

- `01-workspace-home-empty.png`
- `02-workflow-prompt-analysis.png`
- `03-agents-running.png`
- `04-data-chart-export.png`
- `05-paper-review-checklist.png`

## 文件夹说明

- `00-inbox/`：你可以先把还没分类的所有原始截图直接放这里，我会负责识别和归类\n- `01-workspace/`：主工作台、项目列表、建模对话、题目导入、写论文入口
- `02-workflow/`：题意解析、方法选型、求解、灵敏度分析、结果复现
- `03-agents/`：多智能体协作、角色分工、运行状态、任务日志
- `04-data/`：数据导入、数据体检、缺失值、异常值、图表、导出
- `05-paper/`：论文库、论文编辑、图表插入、评审与打分、提交检查
- `06-competition/`：比赛工作台、比赛信息、队伍档案、赛程、倒计时
- `07-misc/`：设置、模型配置、账号状态、其他需要展示的页面

## 截图建议

优先使用完整窗口截图，并尽量保留左侧导航、页面标题和当前项目名称。涉及敏感信息时，可以先打码；不要裁掉能说明功能位置的区域。
