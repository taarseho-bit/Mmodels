## 当前网页中的内容原则

1. 每张截图都先解释“截图里实际发生了什么”。
2. 再说明“这个功能为数学建模解决了什么问题”。
3. 最后说明“它如何进入题意解析、实验、图表或论文交付链路”。
4. 不使用截图中没有出现的功能名或结果数字作为宣传依据。
5. 后续替换正式截图时，只需要替换图片文件和对应说明，不需要重新设计页面结构。
